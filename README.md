# دیده‌بان مناقصات ستاد — وب اپ

-web dashboard for the Setadiran tender monitoring system.

## اجرا

```bash
cd tender-watch-webapp
node server.js
```

سپس در مرورگر باز کنید: `http://localhost:3725`

## امکانات

- **نمایش وضعیت**: تعداد شهرها و موضوعات فعال، آگهی‌های دیده‌شده، آخرین اسکن
- **افزودن شهر**: اضافه کردن شهر جدید به همراه استان
- **افزودن موضوع**: اضافه کردن موضوع پایش با کلیدواژه‌های مرتبط (اختیار: فقط پارک/فضای سبز)
- **روشن/{x} خاموش کردن**: هر شهر یا موضوع را به صورت موقت فعال/غیرفعل کنید
- **اسکن فوری**: اسکن دستی تمام شهرهای فعال
- **گزارش کامل شهر**: استان انتخاب کن → شهر انتخاب کن → PDF کامل با لینک هر اگهی در سامانه ( meltdown‌دارها قرمزند)
- **طراحی زیبا**: رابط کاربری فارسی با انیمیشن‌ها و پاسخ‌گو

## نسخه ۳ (بازنویسی ۲۰۲۶-۰۹-۱۷) — سرعت و پاسخ‌دهی

- **اسکن و PDF در پس‌زمینه**: دکمه «اسکن فوری» بلافاصله پاسخ می‌دهد؛ اسکن در پس‌زمینه اجرا می‌شود و صفحه هر ۱۰ ثانیه به‌روزرسانی می‌شود (قبلی: اتصال HTTP تا پایان اسکن باز می‌ماند)
- **کش ۶۰ ثانیه‌ای**: کلیک متوالی روی اسکن/PDF فوراً جواب می‌دهد
- **بازرسازی هوشمند لیست‌ها**: فقط وقتی تغییر کنند بازرسازی می‌شوند (کاهش بازرسازی ۱۵ ثانیه‌ای + جلوگیری از از دست رفتن فوکوس ورودی‌ها)
- **پولِ زیرپنجره**: وقتی تب غیرقابل مشاهده است پول متوقف می‌شود
- **مسیرها و باینر نود از `import.meta.url` / `process.execPath` گرفته می‌شوند** (بدون مسیرهای سخت‌شده)
- **پورت پیش‌فرض ۳۷۲۵** (محیط `PORT` قابل تغییر): اگر پورت اشغال باشد (یه سرور قدیمی از همین اپ باقی مونده) پیام شفاف می‌دهد و خودکار به پورت بعدی (۳۷۲۶، ۳۷۲۷، ...) بر می‌گردد تا اپ از اول نیفته

## فایل‌ها

- `server.js` — سرور وب (Node.js ES module)
- `public/index.html` — صفحه اصلی فرانت‌اند (تک‌فایلی، بدون وابستگی خارجی)
- `package.json` — اطلاعات پکیج

## امنیت

- هیچ ورودی کاربری به `exec`/`spawn` نمی‌رود — فقط فایل‌های JSON مدیریت می‌شوند
- اسکن با آرگومان‌های ثابت و بدون داده کاربری فراخوانی می‌شود
- صحت ورودی‌ها با تابع تأیید فارسی (Persian-only validation) انجام می‌شود
- body درخواست محدود به ۱ مگابایت است
- `keepAliveTimeout`/`headersTimeout`/`maxRequestsPerSocket` برای جلوگیری از اتصالات رهاشده
